# 升级固件

## 讯为RK3588

1. 打包镜像，生成

执行`./build.sh`，选择`updataimg`。

![打包镜像](../picture/SDK/7.打包镜像.png)

2. 将生成的文件上传到Windows

![选择镜像文件](../picture/SDK/8.选择镜像.png)

路径：`/home/zkb/rk3588_itop/rk3588-linux/rockdev/update.img`

3. 打开RKDevTool，切换模式

切换到`loader`模式。

::: tabs#update

@tab 手动切换

在电源关闭情况下，按住`vol+`键后按下电源开关，等待设备切换到`loader`模式。

![vol+](../picture/SDK/6.vol+.png)

![手动切换](../picture/SDK/4.rkdevtool.png)

@tab 软件切换

![软件切换](../picture/SDK/5.切换模式.png)

@tab 强制进入maskrom

当芯片内部程序不能正常运行时，需要使用这种办法进行烧录。

在电源关闭情况下，按住`BOOT`键后按下电源开关，等待设备切换到`maskrom`模式。

![maskrom](../picture/SDK/11.maskrom.png)

:::

4. 选择升级固件

![选择固件](../picture/SDK/9.固件选择.png)

5. 烧录

![烧录](../picture/SDK/10.烧录.png)
